LUMIERE - IMAGE GUIDE
=====================
Put your images in this folder using the file names below.
Until an image exists, the site shows a dashed placeholder with the expected file name.
(Change names anywhere in index.html / shop.html / product.html or js/main.js if you prefer.)

HOME (index.html)
  hero-1.jpg  hero-2.jpg  hero-3.jpg        -> hero slider  (about 1200x1000)
  cat-skincare.jpg  cat-makeup.jpg  cat-fashion.jpg
  cat-electronics.jpg  cat-home.jpg  cat-accessories.jpg   -> category tiles (4:5)
  promo-1.jpg  promo-2.jpg  promo-3.jpg     -> promo banners
  avatar-1.jpg  avatar-2.jpg  avatar-3.jpg  -> testimonial avatars (square)
  newsletter.jpg                            -> newsletter side image
  gallery-1.jpg ... gallery-4.jpg           -> bottom gallery (3:4)

SHOP BANNERS (shop.html) - one per category, wide (about 1400x400)
  banner-all.jpg  banner-beauty.jpg  banner-skincare.jpg  banner-makeup.jpg
  banner-fashion.jpg  banner-electronics.jpg  banner-home.jpg
  banner-accessories.jpg  banner-offers.jpg  banner-wishlist.jpg
  strip.jpg                                 -> banner at the bottom of the shop page

PRODUCTS (images/products/)
  <id>.jpg      main image, square (1.jpg ... 27.jpg, ids are in js/products.js)
  <id>-2.jpg    optional 2nd gallery image on the product page
  <id>-3.jpg    optional 3rd gallery image on the product page

EDITING PRODUCTS: open js/products.js and add / edit entries in the "products" list.
